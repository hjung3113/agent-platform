# Product Principles

1. Evidence over claims.
2. Human material decisions; machine deterministic admission.
3. Fresh context for bounded work; durable files for continuity.
4. Skills are canonical; commands and harness adapters are thin.
5. Pre-execution plan verification is different from post-execution result verification.
6. Runtime, role, model, and transport are independent axes.
7. Derived summaries are caches, never truth.
8. Failure closes rather than silently falls back.
9. Prefer vertical slices and deep seams over broad speculative abstractions.
10. Start with the smallest mechanism that closes a demonstrated failure.
