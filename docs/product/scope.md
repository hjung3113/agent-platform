# Scope

## In scope
- request refinement and grounding
- durable knowledge/decision memory
- contract admission and run protocol
- task-graph orchestration
- multi-runtime execution through adapters
- independent review and verification
- evidence/finding/receipt lineage
- permission and approval gates
- installation/diagnostics
- optional visual workflow tooling

## Not initially guaranteed
- unconstrained autonomous operation
- arbitrary parallelism
- semantic correctness from LLM judgement alone
- multi-tenant hostile-code isolation
- automatic authority changes
- automatic adoption of every upstream skill
