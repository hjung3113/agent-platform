# Research Archive

This tree intentionally preserves **adopted, rejected, deferred, and contradictory**
patterns from surveyed repositories.

Every research note should state:
- source repository/path
- observed behavior/concept
- evidence status
- adoption decision: ADOPT / ADAPT / DEFER / REJECT / RESEARCH-ONLY
- target scaffold location if adopted
- reason and unresolved risks

Research documents are not normative. They exist so a later designer can revisit
ideas without re-running the entire repository survey.
