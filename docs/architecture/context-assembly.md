# Context Assembly

Priority:
1. approved request/decisions/contracts
2. workflow/task objective and acceptance
3. exact predecessor artifacts/receipts
4. task-scoped open findings
5. immediately relevant repository evidence
6. derived indexes within remaining budget

Exclude by default:
- raw chat transcripts
- unrelated sibling outputs
- resolved findings
- stale summaries
- broad rule catalogs not needed for the task

Use fresh agent context for bounded work and pass references/files rather than inheriting the
orchestrator's conversation.
