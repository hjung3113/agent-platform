# Contract Catalog Draft

| Contract | Writer/Proposer | Publisher | Authority |
|---|---|---|---|
| Request Contract | Intake/Planner | Kernel after human alignment | approved objective/scope/AC |
| Decision Proposal | Human/agent proposal | Kernel after human approval | none until approved |
| Decision Record | Human approval | Kernel | durable material decision |
| Workflow Revision | Planner/Conductor proposal | Kernel | admitted graph/policy |
| Plan Check | Plan Checker candidate | Kernel after digest validation | pre-execution judgement bound to exact plan/workflow digest |
| Context Pack | Context Compiler | Kernel/Host | immutable selection record |
| Attempt Packet | Context Compiler | Kernel/Host | attempt execution contract |
| Runtime Observation | Runtime adapter | Host | observed runtime fact |
| Result | Implementer candidate | Kernel after validation | candidate task result |
| Review | Reviewer/Verifier candidate | Kernel after validation | semantic judgement over exact snapshot |
| Evidence | Host/adapter/test tool | Kernel/Host | observed fact |
| Finding | Reviewer/Verifier/Host | Kernel | unresolved observation |
| Receipt | Kernel | Kernel | terminal or checkpoint result |

Draft schemas should be introduced only when the corresponding vertical slice is implemented.
