# Grill With Docs

Compose the installed `grilling` and `domain-modeling` skills in the same session. Use the active runtime's normal skill-composition mechanism; do not introduce a runtime-specific contract into canonical project artifacts.

`grilling` owns the decision-tree interrogation. `domain-modeling` owns terminology and candidate documentation updates. Project authority rules remain above both: documentation edits do not become authoritative merely because they are written to a canonical-looking path.
